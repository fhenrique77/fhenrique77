<h2 align="left">🚀 Projetos em Destaque</h2>

### 🗺️ ZelaDF — Plataforma Colaborativa de Problemas Urbanos

Plataforma para registrar e visualizar problemas urbanos do Distrito Federal por meio de um mapa interativo.

**Principais funcionalidades:**
- Visualização de ocorrências em mapa interativo.
- Cadastro de problemas urbanos com localização e fotografias.
- Autenticação de usuários.
- Confirmação colaborativa de ocorrências.
- Persistência de dados e armazenamento de imagens.
- Interface responsiva para desktop e dispositivos móveis.
- API complementar em Python/FastAPI, desenvolvida e testada separadamente.

**Tecnologias:** React, TypeScript, Supabase, PostgreSQL, Leaflet, FastAPI e Vercel.

🔗 [Repositório](https://github.com/fhenrique77/ZelaDF)

🌐 [Acessar aplicação](https://zela-df.vercel.app/)

---

### ☕ Coffee Machine 2.0 — Aplicação Full Stack

Aplicação web que simula o funcionamento de uma máquina de café, utilizando uma API REST em Java com Quarkus e uma interface desenvolvida em Angular.

**Principais funcionalidades:**
- Compra de bebidas com validação de recursos.
- Gerenciamento de ingredientes e estoque.
- Operações REST para consulta e atualização do estado da máquina.
- Comunicação entre frontend e backend.
- Testes das regras de negócio.

**Tecnologias:** Java, Quarkus, Angular, TypeScript, REST API e Maven.

🔗 [Repositório](https://github.com/fhenrique77/Coffee_Machine_2.0)

---

### 🤖 Podcast Automation Bot — Automação com Python e IA

Sistema de automação para processamento, edição e publicação de vídeos curtos em plataformas digitais.

**Principais funcionalidades:**
- Download e processamento de conteúdo audiovisual.
- Análise de transcrições com inteligência artificial.
- Seleção de trechos para criação de vídeos curtos.
- Processamento e renderização de vídeos com FFmpeg.
- Automação de navegadores com Playwright.
- Agendamento e gerenciamento de execuções.
- Persistência de registros e prevenção de duplicidades.

**Tecnologias:** Python, Google Gemini, Whisper, FFmpeg, Playwright, SQLite e Shell Script.

🔗 [Repositório](https://github.com/fhenrique77/Automa-o_de_Shorts)

---

### 🌐 Flinkboot — Contribuição Open Source

Contribuição para um projeto open source em Java voltado ao ecossistema Apache Flink.

**Contribuição realizada:**
- Correção do caminho de propriedade utilizado na validação de configurações.
- Adequação do nome da propriedade para o formato utilizado no YAML.
- Atualização de testes de validação.
- Execução e verificação dos testes locais.
- Pull Request aprovado e incorporado ao projeto original.

**Tecnologias:** Java, Maven, JUnit e Git.

🔗 [Pull Request #260 — Contribuição incorporada](https://github.com/Sekelenao/Flinkboot/pull/260)
